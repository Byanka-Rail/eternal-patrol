ETERNAL PATROL v6.39.5 변경사항 — 업데이트 확인 단추 · 앱이 더 자주 확인 · 고정 서명

기준본: v6.39.4.
1. 제목 화면 「업데이트 확인 v6.39.5」 단추(옵션 아래)
- 새 앱(이번 APK)에서는 앱의 업데이트 확인을 바로 부른다 → 새 버전이 있으면 내려받기 창, 없으면 「최신입니다」.
- 예전 앱·브라우저에서는 update.json 을 직접 읽어 비교해 알려 준다.
  예전 앱: 「뒤로 가기 → 업데이트 확인」으로 받으라고 안내. 브라우저: 「새로 불러오기」 단추.
2. 앱의 자동 확인: 예전엔 켤 때 6시간이 지났을 때만 → 이제 켤 때마다·앱으로 다시 돌아올 때마다(30분 안에 거듭된 경우만 건너뜀).
   (이 변경은 새 APK 를 설치해야 적용된다.)
3. 앱이 부르는 통로: window.EternalApp.checkUpdate() · gameVersion().
4. APK
- 앱 버전 표기는 그대로 6.25.5 (빌드 검사가 이 값으로 고정돼 있고, 지금 토큰으로는 빌드 검사 파일을 고칠 수 없다 — workflow 권한 필요).
  앱에 담긴 게임은 6.39.5 이지만 앱은 6.25.5 로 알고 있어, 새로 설치하면 첫 확인 때 같은 내용을 한 번 더 받을 수 있다(무해).
- 고정 디버그 서명 키(app/debug.keystore)로 서명 — 예전엔 빌드마다 새 키라 새 APK 를 옛 앱 위에 설치할 수 없었다.
  이 키로 만든 APK 부터는 앞으로 덮어 설치된다. 단, 지금 설치된 앱과는 키가 달라 **이번 한 번은 지우고 새로 설치**해야 한다
  (앱 메뉴 → 세이브 백업을 먼저).
- 빌드 검사 파일(.github/workflows)은 이번에 못 바꿨다 — workflow 권한이 있는 토큰이 있을 때 버전 번호와 함께 정리.
5. 앱 내 업데이트: update.json → 6.39.5.
