ETERNAL PATROL v6.24.6 — 공식 원본 기반 음성팩 배포
====================================================

목표
----
- 원 제작자/제3자 저장소를 게임 사용자의 다운로드 서버로 사용하지 않음.
- 제3자 변환 바이너리에도 의존하지 않음.
- Supertone 공식 Supertonic 3를 ETERNAL PATROL GitHub Actions가 최초 1회 받아 직접 FP16으로 변환.
- 이후 플레이어는 우리 GitHub Release의 voicepack-v2만 사용.

최초 1회
---------
1. 이 프로젝트 ZIP 내용을 Byanka-Rail/eternal-patrol 저장소에 업로드/교체.
2. GitHub → Actions → Publish Official Supertonic Voice Pack.
3. Run workflow.
4. workflow가 공식 Supertonic 3 고정 revision을 다운로드하고 FP16 변환/검증/패키징함.
5. Releases에서 voicepack-v2 확인.

생성되는 Release assets
-----------------------
- ETERNAL_PATROL_SUPERTONIC3_FP16_V2.zip
- ETERNAL_PATROL_SUPERTONIC3_FP16_V2.json
- ETERNAL_PATROL_SUPERTONIC3_FP16_V2_SHA256.txt

정상이라면 이 workflow는 모델을 바꾸기 전까지 다시 실행할 필요가 없음.
게임 HTML/APK 버전이 올라가도 voicepack-v2를 계속 재사용할 수 있음.

APK
---
1. Actions → Build Android APK → Run workflow
2. artifact: ETERNAL_PATROL_v6.24.6_OFFICIAL_SELFHOST_VOICE_debug_apk
3. APK 설치 후 옵션 → 승조원 음성 → 음성팩 받기
4. 앱은 voicepack-v2 manifest → ZIP → SHA-256 → PACK_INFO 순으로 검증
5. 설치 후 음성 시험

기존 voicepack-v1 설치자
------------------------
- v6.24.6은 PACK_INFO의 pack id, 공식 revision, convertedBy 값을 검사함.
- 예전 voicepack-v1은 새 공식직접변환 팩으로 인정되지 않음.
- 새 팩 설치가 완료될 때 기존 저장경로를 원자적으로 교체하므로 최종적으로 중복 모델을 남기지 않음.
- 새 설치 과정에는 ZIP+압축해제 공간이 필요하므로 약 430MB 이상의 여유 공간을 권장.
