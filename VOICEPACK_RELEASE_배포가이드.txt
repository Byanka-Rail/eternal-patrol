ETERNAL PATROL v6.24.5 — 음성팩 우리 GitHub Release 배포 순서
===============================================================

목표
- 게임 사용자는 Kyumdroid/Hugging Face에서 직접 음성팩을 받지 않음
- Byanka-Rail/eternal-patrol GitHub Release의 voicepack-v1에서만 다운로드
- upstream 출처와 OpenRAIL-M 라이선스는 그대로 고지

최초 1회
1. ETERNAL_PATROL_v6.24.5_ANDROID_SELFHOST_VOICE 프로젝트 내용을
   Byanka-Rail/eternal-patrol 저장소 루트에 반영한다.

2. GitHub → Actions → Publish Supertonic Voice Pack → Run workflow

3. 완료 후 GitHub → Releases에서 voicepack-v1 확인
   아래 3개가 있어야 한다.
   - ETERNAL_PATROL_SUPERTONIC3_FP16_V1.zip
   - ETERNAL_PATROL_SUPERTONIC3_FP16_V1.json
   - ETERNAL_PATROL_SUPERTONIC3_FP16_V1_SHA256.txt

4. 이 음성팩 Release는 같은 voicepack-v1을 계속 쓸 동안 다시 만들 필요가 없다.

APK 빌드
1. Actions → Build Android APK → Run workflow
2. artifact: ETERNAL_PATROL_v6.24.5_SELFHOST_VOICE_debug_apk
3. 내부 app-debug.apk 설치

실기기 확인
1. 옵션 → 승조원 음성
2. 음성팩 받기
3. 화면에 목록 확인 → 다운로드 → SHA-256 검증 → 설치 단계가 진행되는지 확인
4. 음성 시험

기존 v6.24.3/6.24.4 APK에서 이미 음성팩을 받은 경우
- 같은 applicationId와 앱 데이터가 유지되면 기존 supertonic3_fp16_v1 팩을 그대로 사용한다.
- 따라서 덮어쓰기 설치 후에는 200MB를 다시 받을 필요가 없을 수 있다.
- 앱을 삭제한 뒤 재설치하면 앱 전용 데이터도 사라질 수 있으므로 다시 받아야 한다.

참고
- 런타임 다운로드 호스트만 ETERNAL PATROL 쪽으로 옮긴 것이다.
- 원 모델은 Supertone/supertonic-3, FP16 파생은 Kyumdroid/supertonic-3-quant이며
  해당 출처와 라이선스 고지는 제거하면 안 된다.
