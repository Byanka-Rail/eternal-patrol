Distribution design
-------------------
- Model weights are NOT bundled inside the ETERNAL PATROL APK or HTML.
- The player must explicitly choose "음성팩 받기" before model files are downloaded.
- voicepack-v2 is created once on GitHub Actions from the pinned official model and then hosted by the ETERNAL PATROL GitHub Release.
- Normal players download only from the ETERNAL PATROL Release.
- The optional pack includes the official model LICENSE, THIRD_PARTY_NOTICES.txt, CONVERSION_NOTES.txt, and PACK_INFO.json.
- This game uses supplied preset M1-M5 styles and does not clone a real person's voice.
