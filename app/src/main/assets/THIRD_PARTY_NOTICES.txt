Distribution design
-------------------
- Model weights are NOT bundled inside the ETERNAL PATROL APK.
- The player must explicitly choose "음성팩 받기" before model files are downloaded.
- The downloaded pack is stored in the app-private data directory and can be removed from the game options.
- The model repository's LICENSE file is downloaded with the optional pack.
- This game uses only the supplied preset M1-M5 male voice styles and does not clone a real person's voice.
