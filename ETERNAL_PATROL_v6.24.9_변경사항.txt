ETERNAL PATROL v6.24.9 변경사항
================================

[함교 시야]
- 부상 함교 견시의 탐지 시정거리와 실제 관측 캔버스의 시정거리를 같은 공식으로 통일.
- 관측원 AUTO가 켜진 부상 상태에서는 선택 접촉, 없으면 가장 강한 접촉 방위를 함교 시야 중심으로 사용.
- 함교 광각을 120°에서 180°로 확대.
- 시야에 실제로 보이는 표적이 없으면 빈 화면 대신 '이 방위에 육안 표적 없음'과 현재 시정거리를 표시.
- 함교 상단에 방위 눈금을 추가.
- 잠망경의 관측/탐지 확률과 노출도 계산은 변경하지 않음.

[오디오 믹서]
- 효과음 / 배경음 / 승조원 음성 3개 독립 슬라이더 추가.
- 옵션 화면과 함장 명령 패널의 슬라이더가 같은 저장값을 공유.
- 기본값: 효과음 100%, 배경음 75%, 승조원 음성 55%.
- 효과음은 핑·폭뢰·경고·버튼·접촉 스크류 중심.
- 배경음은 자함 스크류/추진·디젤·전동기·바다/바람 지속음 중심.
- 기존 끔/조용히/표준/청음강조/영화적 프리셋은 유지하며 새 슬라이더는 프리셋 위에 곱해짐.

[TTS 발음]
- 화면 문구는 바꾸지 않고 TTS로 넘기는 복사본만 정규화.
- kn/kt/kts → 노트, km/m → 킬로미터/미터, rpm → 알피엠, ° → 도, % → 퍼센트.
- C1 같은 접촉번호 → '씨 1', U-boat/ASDIC/HF/DF 기본 읽기 보정.
- 이후 발음 사전은 HTML만 업데이트해 확장 가능.

[음성 질감]
- Android 음성 볼륨 하한을 55%에서 2%로 내려 실제 믹싱 가능.
- 합성 PCM에 약한 저역 컷, 고역 완화, 소프트 컴프레션, 매우 짧은 초기반사를 적용.
- 긴급 보고는 반사를 더 줄여 명료도를 유지.
- Supertonic 모델/voicepack-v3는 변경 없음.

[영향 없음]
- 어뢰·탐지·AI·사격해법·캠페인/War 저장 구조
- voicepack-v3 모델 파일 및 GitHub Release
