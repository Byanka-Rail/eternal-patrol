ETERNAL PATROL v6.26.0 변경사항 — 계기 층 (Instruments)

기준본: v6.25.6(발사관 캡). 이번 차수는 함내 탭 조작을 계기로 바꾸고, 발사를 길게 누르기로 바꾼다.
게임 규칙·시뮬레이션·세이브 구조는 건드리지 않음.
블록: <style id="ep-v626-instrument-style"> + <script id="ep-v626-instrument-script"> (</body> 직전).
v6.25.6 의 발사관 블록은 이 블록에 합쳐졌다(같은 CSS). 이 블록 하나를 지우면 v6.25.5 로 돌아간다.

0. 함내 탭 고정 해도 — 절반 높이
- #boatChartDock 의 해도 캔버스를 190px 로. (원래 CSS 는 188px 였으나 캔버스의 인라인 height:380px 가 이겨서 전체 높이로 나오고 있었다. !important 로 바로잡음.)

1. 조타 — 컴퍼스
- 링을 끌면 명령 침로가 따라간다(호박색 표식). 러버선이 실제 침로.
- 옆 톱니: ◂10° · ◂1° · 침로 유지 · 1°▸ · 10°▸. 기존 btnHl/btnHold/btnHr 를 대신 누른다.
- 좌 10°/침로 유지/우 10° 행과 침로 슬라이더(rgHead)는 감춤(DOM 유지, 값 동기화).
- 방향타 5단추는 붙은 선택 스위치 모양.

2. 기관 — 전신기 레버
- #tgRow 위에 반원 전신기. 손잡이를 끌면 가장 가까운 단의 기존 단추를 대신 누른다.
- 단마다 물 위/물속 실제 kn 표기(telegraphKn). 미세조정 슬라이더는 그대로. #tgRow 는 축약형으로 남음(교범·훈련 목표 요소 유지).

3. 심도 — 세로 심도계
- 호박 손잡이를 끌면 issueDepthOrder. 바늘은 실제 심도.
- 눈금: 잠망경 심도선(파랑) · 수온약층 띠(파랑) · 안전심도 25m 전 경고 띠(호박)와 안전심도선 · 그 아래 위험 띠(빨강) · 해저(강철색). 눈금 최대는 압궤심도와 해저 중 얕은 쪽.
- 왼쪽 표식(잠망경·약층 위·약층 아래)은 #depRow 의 프리셋 단추를 대신 누른다. 갈 수 없는 심도의 표식은 그려지지 않는다.
- #depRow 는 심도계 오른쪽 한 열로 이동. 심도 슬라이더(rgDep)는 감춤.

4. 발사 — 길게 누르기
- 짧은 탭은 무시, 약 0.5초 채우면 기존 btnFire 클릭이 한 번 통과. 키보드(Enter/Space)는 그대로 통과.
- 발사 가능 판정(fireGate)은 기존 규칙 그대로.

5. 색·조명
- 계기 유리는 해도판 토큰(--chartBg/--chartGrid/--chartInk)을 써서 네 조명 모두 어두운 유리 위 야광 눈금.
- 호박=함장이 답할 명령 · 초록=준비 · 빨강=위험 규칙 유지.

6. 검증
- 인라인 스크립트 문법 통과, 중복 DOM ID 0, 모바일 뷰포트 pageerror 0.
- 컴퍼스 드래그 → orders.heading, 레버 드래그 → orders.speed.telegraph, 심도계 드래그 → orders.depth 변경 확인.
- 발사: 탭 0회 통과 · 길게 누르기 1회 통과 확인. 함내 탭 해도 캔버스 높이 190px 확인.

7. 유지
- app/src/main/assets/index.html 동일 HTML로 갱신. Android 껍데기·음성·세이브 키 변경 없음. <title> v6.26.0.
