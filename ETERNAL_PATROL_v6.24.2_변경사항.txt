ETERNAL PATROL v6.24.2 변경사항
================================

[Android 음성 엔진]
- 기존 v6.23.7 Android WebView 패키지를 기준으로 window.EternalVoice 네이티브 브리지 추가.
- ONNX Runtime Android 1.29.0 의존성 추가.
- Supertonic 3 한국어 M1~M5 프리셋 음성을 기기에서 합성.
- 음성 생성/재생은 단일 작업열로 직렬화하고 긴급 우선순위는 대기열을 정리할 수 있게 함.
- 앱 백그라운드/종료 시 음성 재생 및 추론 취소.

[선택 음성팩]
- 모델은 APK에 내장하지 않고 옵션에서 최초 1회 명시적으로 내려받음.
- Android 호환성 우선으로 Kyumdroid/supertonic-3-quant FP16 ONNX 사용.
- 약 200MB 설치, 앱 전용 저장소 사용, 옵션에서 삭제 가능.
- 중간 다운로드 파일을 유지하고 서버가 지원하면 이어받기 사용.
- 음성팩 미설치 또는 오류 시 게임은 기존 텍스트 전용으로 계속 동작.

[HTML]
- 버전 6.24.2로 갱신.
- 음성팩 표시를 초기 INT8 약 100MB에서 안정형 FP16 약 200MB로 교정.
- 역할별 M1~M5/속도 매핑, 끔·중요 보고·모든 전술 보고 설정 유지.
- 시작 화면 짧은 AI 합성음성 고지 및 옵션 상세 제3자 고지 유지/갱신.

[Android 패키지 정합성]
- versionName 6.24.2 / versionCode 62402.
- MainActivity의 오래된 BUNDLED_GAME_VERSION 6.23.6 불일치를 6.24.2로 수정.
- GitHub Actions artifact 명칭을 v6.24.2로 갱신.
- arm64-v8a만 패키징해 불필요한 ONNX Runtime ABI 용량을 줄임.

[보존]
- 기존 GitHub HTML 자동업데이트, localStorage origin, 세이브 백업/복원 유지.
- 전투 계산·탐지·청음·AI·역사전·Campaign/War 저장 코어 미변경.

- DOM id 570개, 중복 0.
- 신규/수정 Java 소스 javac 파싱 단계에서 syntax-like 오류 0 확인.
