ETERNAL PATROL v6.29.0 변경사항 — 기초 훈련 「첫 출항」

기준본: v6.28.1. 블록: <style id="ep-v629-tutorial-style"> + <script id="ep-v629-tutorial-script"> (</body> 직전). 기존 교범·전투 훈련은 그대로 둔다.

1. 무엇을 가르치나 — 세 가지만
- ① 접근 · 관측: 함내 → 조타(컴퍼스로 소리 방위에 침로) → 기관(반속) → 시간 ×4 → 1,800m 안 → 심도(잠망경 심도) → 관측 탭 → 잠망경 올림 → 화면 끌어 배 찾기 → 관측 기록
- ② 두 번 보고 쏜다: 20초 뒤 다시 관측 기록 → 공격 탭 → 표적판에서 표적 → 1관 → 발사(길게) → 어뢰 주행(×4 자동)
- ③ 잠항 · 이탈: 잠망경 내림 → 함내 → 심도(약층 아래) → 기관(미속) → 조타(소리 반대 방향)
- 24단계. 끝 카드에서 「이 판을 이어서」 또는 「처음 화면으로」.

2. 어떻게 막나
- 그 단계에 필요한 단추·계기만 누를 수 있다. 다른 단추·계기·탭은 눌러도 반응하지 않고(캡처 단계에서 차단) 화면이 어두워진 채 목표만 호박색 테로 밝혀진다.
- 빈 곳 스크롤은 그대로 된다. 계기가 대신 누르는 숨은 단추(btnHl 등)는 isTrusted=false 라 차단하지 않는다.
- 목표가 화면 밖이면 단계 시작 때 한 번 끌어온다. 설명 카드는 목표를 가리지 않는 위·아래 중 한쪽에 붙는다.
- 진행 중 접촉 띠(#sheet)는 감춘다. 「그만두기」로 언제든 빠질 수 있고 판은 이어진다.

3. 판
- 빠른 전투 창을 거쳐 시작: 난이도 하 · 단독선 사냥 · 맑음 · 시드 1000(북대서양 · Type VIIC · 상선 1 · 호위 0). 승조원 완전 수동으로 바꾼다.
- 완료 판정은 U.state()에서 읽는다(침로 명령·전령 kn·시계·심도·잠망경·관측 수·해법·발사관 선택·어뢰 수·표적 생사). 표적 방위·거리는 판정용으로 실제 위치를 쓴다.
- 표적 선택·발사관 단계 진입 시 이미 선택된 것을 풀어 손으로 다시 고르게 한다.

4. 제목 화면
- 「첫 출항 — 기초 훈련 · 접근 · 두 번 보고 발사 · 잠항 이탈 · 5분」 단추를 「초계 개시」 위에 둔다.
